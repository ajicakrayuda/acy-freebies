# ACY Freebies

Source code gratis dari **ACY Partner Indonesia**: landing page, dashboard, dan app kecil dalam HTML, CSS, dan JavaScript murni.

- Galeri dan demo: https://ajicakrayuda.github.io/acy-freebies/
- Tiap project ada di `projects/<nama-project>/`, lengkap dengan README singkat.
- Lisensi MIT: bebas dipakai untuk proyek pribadi maupun komersial.

## Cara pakai

1. Buka galeri, pilih project yang kamu mau, lalu klik **Lihat demo**.
2. Klik **Ambil kode** untuk membuka foldernya, lalu download atau salin `index.html`.
3. Buka file itu di browser. Nggak perlu build atau server.

## Isi repo

| Path | Isi |
|---|---|
| `index.html` | Halaman galeri semua project |
| `projects.json` | Daftar project yang tampil di galeri |
| `projects/` | Satu folder per project |
