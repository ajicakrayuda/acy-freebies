# Servora - Dashboard Pantau Server

Dashboard pantau server dengan data contoh lokal. Ada ringkasan status, grafik garis SVG (CPU dan memori), daftar server dengan pencarian dan filter, serta tema terang, gelap, atau ikut perangkat. "Servora" adalah merek fiktif.

## Isi file

| File | Isi |
|---|---|
| `index.html` | Struktur halaman: header, ringkasan, grafik, daftar server |
| `style.css` | Tampilan, tema terang/gelap, dan layout responsif |
| `script.js` | Data contoh, gambar grafik SVG, filter, tema, dan keadaan memuat/kosong/salah |

## Cara pakai

1. Download folder ini.
2. Buka `index.html` di browser. Nggak perlu build atau install apa pun.
3. Ganti data di bagian `servers` pada `script.js` dengan data kamu sendiri.
